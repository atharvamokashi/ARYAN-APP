# StudySpace

A responsive student study manager for Geography, Civics, History, Maths, Marathi, Hindi and Science.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` (and this README, if desired) to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

## Features
- Subject-specific assignments with due dates
- Add, edit, delete and complete assignments
- Autosaving subject notes
- Subject-wise PDF library
- Progress dashboard
- Responsive desktop and mobile layout

## Data storage
Assignments and notes are saved in the browser's local storage. PDFs are saved in browser IndexedDB. Data is local to the browser/device and is not automatically synced between devices. Clearing browser data may remove saved information.
